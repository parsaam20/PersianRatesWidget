# نرخ لحظه‌ای بازار (PersianRatesWidget)

ویدجت رومیز سبک و نیتیو برای **ویندوز ۱۰ و ۱۱** که نرخ لحظه‌ای دلار، تتر، درهم و طلا را با رابط کاملاً فارسی و راست‌به‌چپ نمایش می‌دهد. این برنامه با **C# / WPF (.NET 8)** نوشته شده و بدون نیاز به نصب هیچ ابزار جانبی، مستقیم روی دسکتاپ اجرا می‌شود.

## نرخ‌های نمایش‌داده‌شده

| ردیف | ارز / کالا | توضیح | منبع |
|---|---|---|---|
| ۱ | دلار آمریکا | USD — بازار آزاد | tgju.org |
| ۲ | تتر | USDT — تتر | tgju.org (با جایگزین Nobitex) |
| ۳ | درهم امارات | AED — بازار آزاد | tgju.org |
| ۴ | طلای ۱۸ عیار | قیمت هر گرم (۷۵۰) | tgju.org |
| ۵ | طلای ۲۴ عیار | قیمت هر گرم (۹۹۹.۹) | tgju.org |

همه قیمت‌ها به **تومان** نمایش داده می‌شوند (ریال به‌صورت خودکار به تومان تبدیل می‌شود) و درصد تغییر نسبت به قیمت قبلی با رنگ سبز (افزایش) یا قرمز (کاهش) نشان داده می‌شود.

## ویژگی‌ها

- **رابط کاملاً فارسی و راست‌به‌چپ (RTL):** با `FlowDirection="RightToLeft"` در WPF، اعداد فارسی (۰-۹)، جداکننده هزارگان و فونت وزیرمتن (با بازگشت خودکار به Segoe UI / Tahoma).
- **استایل شیشه‌ای تیره مطابق ویندوز ۱۱:** کارت شناور کم‌عرض (۲۹۶ پیکسل) بدون حاشیه پنجره، با سایه نرم و گوشه‌های گرد.
- **غيرمزاحم:** عدم نمایش در تسکبار، امکان کشیدن و جابه‌جایی با ماوس و حالت «همیشه روی صفحه» (Pin).
- **به‌روزرسانی خودکار:** دریافت نرخ‌های جدید هر **۶۰ ثانیه** به‌صورت خودکار، به‌علاوه دکمه تازه‌سازی دستی.
- **حالت آفلاین هوشمند:** بررسی اتصال اینترنت، مدیریت خطاهای شبکه و تایم‌اوت بدون کرش؛ در صورت قطعی، پیام فارسی نمایش داده شده و **آخرین نرخ‌های ذخیره‌شده** از کش محلی نشان داده می‌شود.
- **نوار اعلان (System Tray):** با زدن دکمه کمینه، برنامه به تسک‌تری می‌رود و از منوی فارسی آن می‌توان نمایش/مخفی، به‌روزرسانی فوری یا خروج انجام داد.
- **بدون نیاز به نصب دات‌نت (در نسخه EXE):** خروجی self-contained به‌صورت یک فایل EXE مستقل اجرا می‌شود.

## روش‌های نصب و اجرا

### روش ۱ — نصب با فایل Setup (پیشنهادی)

۱. فایل `PersianRatesWidget_Setup_v1.0.0.exe` را بسازید (بخش «ساخت فایل نصب» پایین‌تر مراجعه کنید) یا از GitHub Actions Artifact دریافت کنید.
۲. فایل را اجرا کنید. نصب در سطح کاربر (بدون نیاز به ادمین) در مسیر زیر انجام می‌شود:

```text
%LocalAppData%\Programs\PersianRatesWidget
```

۳. در مراحل نصب می‌توانید دو گزینه را فعال کنید:
- **ایجاد میانبر روی دسکتاپ**
- **اجرای خودکار هنگام بالا آمدن ویندوز** (میانبر در پوشه Startup)

### روش ۲ — اجرا مستقیم از سورس

```powershell
# کلون کردن مخزن
git clone https://github.com/parsaam20/PersianRatesWidget.git
cd PersianRatesWidget

# اجرا
dotnet run
```

### روش ۳ — ساخت EXE مستقل (بدون نیاز به نصب دات‌نت روی سیستم هدف)

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
```

خروجی:

```text
.\publish\PersianRatesWidget.exe
```

> نکته: اگر دات‌نت ۸ دسکتاپ روی سیستم نصب است، با `--self-contained false` خروجی خیلی سبک‌تر (حدود ۲۰۰ کیلوبایت) خواهد بود.

### اجرای دستی EXE بدون نصب

کافی است فایل `PersianRatesWidget.exe` را در پوشه‌ای کپی کرده و دوباره اجرا کنید. برای اجرای خودکار در شروع ویندوز، کلیدهای `Win + R` را بزنید، `shell:startup` را تایپ کنید و میانبر برنامه را در آن پوشه بگذارید.

## ساخت فایل نصب (Setup.exe)

### بیلد محلی (روی ویندوز)

```bat
build_installer.bat
```

این اسکریپت ابتدا EXE را با `dotnet publish` می‌سازد و سپس با Inno Setup فایل نصب را تولید می‌کند:

```text
installer_output\PersianRatesWidget_Setup_v1.0.0.exe
```

### بیلد خودکار با GitHub Actions

پس از هر push روی شاخه `main` (یا اجرای دستی workflow) فایل `Build Windows Installer` موارد زیر را انجام می‌دهد:

1. نصب .NET 8 روی رانر ویندوزی
2. ساخت EXE مستقل (`dotnet publish`)
3. نصب Inno Setup و ساخت `Setup.exe`
4. آپلود Artifact با نام `PersianRatesWidget-Installer` شامل:
   - `installer_output\*.exe` (فایل نصب)
   - `publish\PersianRatesWidget.exe` (نسخه پرتابل)

اجرای دستی: از تب **Actions** →workflow **Build Windows Installer** → **Run workflow**.

| کنترل | عملکرد |

| ↻ | به‌روزرسانی دستی نرخ‌ها |
| 📌 | روشن/خاموش کردن حالت «همیشه روی صفحه» |
| — | انتقال به نوار اعلان (System Tray)؛ با دابل‌کلیک روی آیکان دوباره نمایان می‌شود |

**نقطه وضعیت (کنار عنوان):** سبز = اتصال موفق، نارنجی = در حال دریافت، قرمز = آفلاین یا خطا.

## منابع داده و نحوه کار

- منبع اصلی: `https://call.tgju.org/ajax.json` (نرخ‌های بازار آزاد ایران)
- منبع جایگزین برای تتر: `https://apiv2.nobitex.ir/v3/orderbook/USDTIRT` (در صورت نبود تتر در پاسخ TGJU)
- همه نرخ‌ها از ریال به تومان تبدیل می‌شوند (تقسیم بر ۱۰) با گردکردن مناسب.
- **کش محلی:** هر دریافت موفق در فایل `%LocalAppData%\PersianRatesWidget\rates_cache.json` ذخیره می‌شود؛ هنگام آفلاین بودن، آخرین نرخ‌های معتبر از همین فایل نمایش داده می‌شود.

## سفارشی‌سازی

- **فاصله به‌روزرسانی:** مقدار `TimeSpan.FromSeconds(60)` در `MainWindow.xaml.cs` را تغییر دهید.
- **افزودن ارز یا طلای المزيد:** یک کلید جدید به `Rates` در `MainWindow.xaml.cs` و یک فراخوانی `TryExtractTgjuItem` در `RateService.cs` اضافه کنید.
- **تغییر منبع داده:** هر API جایگزینی که JSON برمی‌گرداند را در `Services/RateService.cs` جایگزین کنید.
- **رنگ‌ها و فونت:** در `MainWindow.xaml` (پس‌زمینه `#EB141821`، رنگ سبز `#22C55E`، قرمز `#EF4444`).
